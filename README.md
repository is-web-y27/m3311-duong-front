# Лабораторная работа №1

## Описание
Данная лабораторная работа направлена на создание макета сайта без использования CSS, только с помощью HTML. В рамках работы необходимо разработать сайт по теме "ROYAL Travel" — туристическая платформа, предлагающая туры по России. Основная цель — изучить ключевые HTML-теги и научиться правильно их использовать.

## Задачи

### Подготовка среды разработки:
- Установить текстовый редактор (например, Visual Studio Code).

### Определение темы и создание макета:
- Выбрана тема: туристический сайт ROYAL Travel.
- Нарисован макет сайта с расположением баннера, меню, контента и формы контактов.
- Изображение макета добавлено в репозиторий (`layout.jpg`).

### Начальная настройка страницы:
- Кодировка UTF-8.
- Указаны ключевые слова и описание в мета-тегах.
- Подключение файла outlines.css при необходимости.

### Создание структуры сайта:
- Использованы теги `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.
- Установлен язык страницы: `vi`.
- Добавлен заголовок страницы.
- В файле README.md указаны ФИО, номер группы и тема проекта.

### Логическая структура:
- Использованы теги `<main>`, `<header>`, `<footer>`.
- Применены теги `<section>`, `<nav>`, `<article>`, `<aside>`, `<h1>`-`<h6>`, `<p>`.
- Добавлены списки `<ul>`, `<ol>` для описания услуг.
- Вставлен snippet кода с тегами `<pre>`, `<code>`.
- Добавлена цитата и формула успеха с `<blockquote>`, `<cite>`.
- Выделены важные моменты с помощью `<strong>`, `<em>`, `<del>`, `<ins>`.

# Лабораторная работа №2 — Применение каскадных таблиц стилей

## Описание  
Цель лабораторной работы — научиться создавать и применять стили к HTML-элементам с помощью CSS.  
Каждый элемент должен выглядеть завершённым, приятным глазу и гармонировать с остальными частями страницы.  
Для подбора цветовой палитры использованы сервисы:  
- [Adobe Color](https://color.adobe.com/ru/)  
- [Colorscheme.ru](https://colorscheme.ru/)

Работа выполнена на основе сайта, созданного в лабораторной работе №1 — ROYAL Travel.

## Задачи

### Подключение CSS:
- Создан файл `style.css` и подключён ко всем HTML-страницам через `<link>`.
- Все стили вынесены из HTML в отдельный файл.

### Стилизованные элементы:
- Стилизованы все элементы: заголовки, абзацы, списки, изображения, блоки, навигация, aside, footer.
- Использованы селекторы по методологии БЭМ: `.header__logo`, `.nav__item`, `.tour__card`, `.section`, `.footer`.

### Работа с изображениями:
- Добавлены изображения с пояснительным текстом: Saint Petersburg, Moscow, Kazan, Sochi, Vladivostok, Murmansk, Kaliningrad.
- Изображения стилизованы: `max-width`, `border-radius`, `box-shadow`, `margin`.

### Применённые CSS-свойства:
- Внутренние и внешние отступы: `padding`, `margin`;
- Цвет фона и текста: `background-color`, `color`;
- Тени и обводки: `box-shadow`, `border-radius`;
- Подключён шрифт `Roboto` через Google Fonts;
- Размеры шрифта с использованием `em`;
- Межстрочные и межбуквенные интервалы: `line-height`, `letter-spacing`;
- Насыщенность шрифта: `font-weight`;
- Выравнивание текста: `text-align`;
- Стилизация текста: `text-transform`, `text-decoration`, `em`, `strong`, `del`, `ins`;
- Регистр символов: `uppercase`, `capitalize`.

### Дополнительные улучшения:
- Навигационная панель оформлена с логотипом слева и ссылками справа с помощью Flexbox.
- Footer закреплён внизу страницы с помощью `min-height: 100vh` и `flex: 1` в контейнере `body`.

# Лабораторная работа №3 — Адаптивная верстка

## Описание  
Цель лабораторной работы — научиться создавать адаптивный интерфейс сайта, корректно отображающийся на различных устройствах: десктопах, планшетах и мобильных телефонах. Работа выполнена на основе проекта ROYAL Travel, разработанного в предыдущих лабораторных.

## Задачи

### Подключение адаптивных стилей:
- Создан отдельный файл `responsive.css` и подключён ко всем HTML-страницам.
- Использованы `@media`-запросы для экранов шириной:
  - `max-width: 1024px` — планшеты;
  - `max-width: 768px` — мобильные устройства.

### Адаптация навигации:
- Навигационная панель перестраивается в вертикальный список на мобильных устройствах.
- Элементы меню выравниваются по центру, добавлены отступы между пунктами.

### Адаптация контента:
- Карточки туров (`.tour__card`) переходят из 3-колоночной сетки в 1-2 колонки в зависимости от ширины экрана.
- Изображения масштабируются с помощью `max-width: 100%`, `height: auto`.
- Использованы гибкие единицы измерения: `%`, `em`, `rem`, `vw`, `vh`.

### Адаптация footer:
- Footer остаётся внизу страницы и масштабируется по ширине экрана.
- Текст выравнивается по центру на мобильных устройствах.

### Дополнительные улучшения:
- Использованы свойства `flex-wrap`, `grid-template-columns`, `gap` для адаптации макета.
- Проверено отображение на разных разрешениях с помощью DevTools.
- Обеспечена читаемость и удобство навигации на всех типах устройств.

# Лабораторная работа №4 — Добавление пользовательского интерактивного взаимодействия

## Описание  
Цель лабораторной работы — научиться взаимодействовать с элементами и браузером, используя язык программирования JavaScript. Работа выполнена на основе проекта ROYAL Travel, разработанного в предыдущих лабораторных.

## Задачи

### Добавление новых страниц:
- Созданы страницы `index.html`, `about.html`, `tours.html`, `contact.html`, соответствующие пунктам меню.
- Обеспечена корректная навигация между страницами.

### Создание и подключение скрипта:
- Создан файл `script.js` и подключён ко всем HTML-страницам через тег `<script>` с атрибутом `defer`.
- Скрипт размещён в отдельной папке проекта.

### Отслеживание загрузки страницы:
- Использована конструкция IIFE для подписки на событие `window.onload`.
- В подвале сайта отображается информация о времени загрузки страницы, рассчитанная с помощью `performance.now()`.

### Интерактивность меню:
- Реализованы эффекты наведения на пункты меню с помощью CSS.
- Добавлены плавные переходы (`transition`) для изменения цвета и подчёркивания.

### Обработка активного пункта меню:
- С помощью JavaScript определяется текущий путь (`location.pathname`).
- Активному пункту меню добавляется CSS-класс `active`.
- Обработан случай, когда разные страницы имеют одинаковое имя файла, но разные пути.

## Дополнительные улучшения:
- Проверена работа скрипта на всех страницах.
- Убедились, что обработка событий не мешает добавлению других слушателей.
- Время загрузки страницы соответствует данным из вкладки «Сеть» DevTools.
- Навигация адаптирована для мобильных устройств (см. Lab 3).

# Лабораторная работа №5 — Разметка веб-форм в runtime и работа с пользовательскими хранилищами

## Описание  
Цель лабораторной работы — получить практические навыки по созданию интерактивной веб-формы, которая позволяет добавлять и изменять элементы после загрузки страницы (в runtime), с сохранением данных в локальном хранилище браузера. Работа выполнена на основе проекта ROYAL Travel, разработанного в предыдущих лабораторных.

## Задачи

### Создание страницы с формой:
- Создана отдельная страница `feedback.html` для сбора обратной связи от пользователей.
- На странице размещена форма с полями: ФИО, email, комментарий.
- Использованы элементы `<form>`, `<input>`, `<textarea>` и `<button>`.

### Валидация данных:
- Реализована встроенная HTML-валидация с атрибутами `required`, `type="email"` и др.
- Дополнительно реализована JavaScript-валидация при отправке формы.

### Добавление элементов в runtime:
- После отправки формы, данные отображаются на странице без перезагрузки.
- Использован шаблон `<template>` для разметки добавляемых элементов.
- DOM-элементы создаются динамически на основе шаблона.

### Сохранение данных:
- Все введённые данные сохраняются в `localStorage`.
- При повторной загрузке страницы, сохранённые элементы автоматически отображаются.

### Редактирование элементов:
- У каждого добавленного элемента есть кнопка «Справить».
- При нажатии открывается `prompt`, позволяющий изменить текст комментария.
- Изменения сохраняются в `localStorage` и отображаются без перезагрузки.

### Стилизация:
- Добавленные элементы стилизованы в соответствии с общей визуальной темой сайта ROYAL Travel.
- Использованы классы `.feedback-item`, стили кнопок и отступы для визуальной гармонии.

## Дополнительные улучшения:
- Использована конструкция IIFE для изоляции логики скрипта.
- Обеспечена адаптивность формы и списка отзывов на мобильных устройствах.
- Проверена работа функциональности в разных браузерах и при перезагрузке страницы.
